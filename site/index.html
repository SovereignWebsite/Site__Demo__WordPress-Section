A demo for web agencies

A section fed from WordPress

Demo. This page is a made-up example for web agencies, not work for any of the sites shown. It is built from their public WordPress data and is not affiliated with them.

The idea: a client keeps WordPress for writing, and the agency adds a fast, static section anywhere that shows the latest posts. This page reads a site's public WordPress feed (/wp-json/wp/v2/posts) in your browser and lays out the titles, dates and links. Nothing is copied or stored; every link goes to the original.

Loading the latest posts...

How an agency would use it

  1. Keep the client's WordPress for writing posts.
  2. Add this section to a static Sovereign Website: it reads the public feed and needs no plugin, no server and no login.
  3. Style it to the site's design; the client's site stays fast and can move host at any time.

The six sites were picked as popular public WordPress sites whose feed is open to browsers, checked on 23 November 2026.
